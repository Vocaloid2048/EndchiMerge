# UI

面板裝飾與非角色類的介面素材。

## Expected contents

| 用途 | 說明 |
| --- | --- |
| 面板底材 | 若深色面板需要貼圖質感而非純色，放這裡 |
| 蛇形箭頭 | MELTING LIST 的 U-turn（`↴` / `↵`）與尾箭頭 |
| 技能格徽章 | ①②③ 的底板（若不走純 CSS） |
| 角括號 | 「」選取態的四段折線（若不走 Canvas 繪製） |

## Notes

- 純 CSS 能做的就不要放素材 —— 面板圓角、描邊、簡單箭頭優先以 CSS / Canvas 繪製，
  減少檔案數量與載入成本。
- 背景美術**不放這裡**。背景是獨立項目，待使用者提供後另議（`design.md` §9 Q1）。
- 缺檔時所有裝飾退化為純色或隱藏，不影響功能。
