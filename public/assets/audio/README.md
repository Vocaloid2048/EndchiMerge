# Audio

音效與背景音樂。全部為可選 —— 檔案不存在時 `SoundPlayer` 為 no-op，遊戲照常運作。

## Expected contents

事件清單取自 `design.md`：(1) 放下、(2) 合成、(3) 背景音樂、(4) 使用技力。

| 檔案 | 觸發時機 |
| --- | --- |
| `drop.*` | 方團團成功投放 |
| `merge.*` | 兩個同級方團團合成 |
| `skill.*` | 技能施放且扣減技力成功 |
| `bgm.*` | 背景音樂，循環播放 |

## Notes

- 使用者已確認**先留 on-click listener 與 SoundPlayer**，素材稍後再補。
- 音樂為獨立開關（工具列音符鍵），與音效分開控制。
- 完整格式與取樣率待定；加入前先確認授權。
