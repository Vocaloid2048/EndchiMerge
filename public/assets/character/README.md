# Character（方團團 / Endchi）

方團團的手繪角色素材。本目錄**取代**舊的 `sprites/`。

## 命名規則

| 格式 | 用途 |
| --- | --- |
| `<角色名>_img.webp` | 完整角色圖，**遊戲使用的格式** |
| `<角色名>_icon.webp` | 縮圖／圖示。**目前未使用**；只有製作「對外發佈版」時才需要由原始向量稿導出 |

`public/config/levels.json` 的 `sprite` 欄位是**相對於 `public/assets/`** 的路徑，例如
`"character/萊萬汀_img.webp"`。

## 輸出規格（勿破壞）

所有 `_img.webp` 一律遵守同一組規格。**這是渲染器能用單一組常數對齊物理與畫面的前提。**

| 項目 | 值 |
| --- | --- |
| 畫布 | **512 × 512**，RGBA |
| 編碼 | **無損 WebP**（`lossless`）。素材為平塗色塊，無損比有損更小且 alpha 邊緣精確 |
| body 外框 | **304 × 304 px**，邊長＝角色方形身體**含描邊外緣** |
| body 中心 | **(256, 328)**（x 置中；y 偏下，因為裝飾多在身體上方） |
| 留白 | 全部為**完全透明**（`alpha = 0`），不可使用白色或任何不透明填充 |
| 縮放 | 等比縮放，**永不拉伸** |

有了固定規格，渲染器只需三個常數就能把 body 對到碰撞圓：

```ts
const SPRITE_SIZE  = 512;   // 畫布邊長
const SPRITE_BODY  = 304;   // body 邊長
const SPRITE_ANCHOR = { x: 256, y: 328 };   // body 中心
const scale = (2 * radius) / SPRITE_BODY;   // radius 為該級碰撞半徑
```

`levels.json` 因此**不需要**存放每個角色的尺寸或偏移——所有對齊資訊都在這裡。

## 為什麼要統一 body 尺寸

原始向量稿的 body 一律是 251×251，但各角色的 `viewBox` 不同（256 ～ 419 寬）。
若直接把每個稿子光柵化成 512 寬，body 會落在 **306.7 ～ 502.0 px**，相差 **38.9%**。
那會令「畫面上的身體」與「碰撞圓」對不上，而對不對得上是這個遊戲的核心手感。

因此導出流程會**以 body 為基準正規化**：每個角色等比縮放至 body 恰好 304 px，再把 body 中心
放到 (256, 328)。結果實測為 304 ± 2 px（±2 來自原稿描邊本身的像素取整）。

304 這個數字不是隨手挑的：它剛好是所有角色都能塞進 512×512 的**最大值**（受 `訣` 的寬裝飾限制），
同時**不需要對任何角色做放大**（最小的 body 原稿為 306.7 px），因此沒有重取樣損失。

## 契約（勿破壞）

1. **不透明實心、無鏤空。** 輪廓白框由 alpha 剪影推導；任何完全透明的內部破洞都會在邊框上打洞。
2. **留白必須透明。** 若改成白色填充，alpha 剪影會變成整個畫布，輪廓白框與量測全部失效。
3. 描邊是美術的一部分，保留；**不要**為了對齊而裁掉裝飾。
4. **檔名必須與 `levels.json` 的 `sprite` 欄位完全一致**（含中文）。
5. 碰撞形狀**一律為圓**，與輪廓無關；視覺對齊由上面的三個常數處理。
6. 原始向量稿保存在 repo **之外**（`Assets/`）——它是唯一能重新導出正確 body 對齊的來源。
   日後換素材時請一併更新本節的規格數字。

## 元數據簽名（強制）

每個素材都必須帶有**不可見的元數據簽名**（作者／授權／日期）。由
`scripts/sign-assets.mjs` 產生，並由 `.githooks/pre-commit` 在每次 commit 時自動補上。

```sh
npm run sign          # 就地補簽（可重複執行，不會產生多餘 diff）
npm run sign:check    # 只驗證，未簽名則非零退出（CI 用）
```

> 簽名是**署名與溯源，不是防拷貝**。SVG / PNG / WebP 都可由使用者直接編輯，簽名可被移除。
> 真正的保護是授權聲明 ＋ 署名 ＋ git 時間戳。機制細節見 `docs/asset-signatures.md`。

## 缺檔行為

素材缺失或無法載入時，遊戲退回**程式生成的佔位圓形**（依該級碰撞半徑繪製）。
遊戲永不因素材缺失而崩潰——只是看起來不對。詳見瀏覽器 console 的警告。
