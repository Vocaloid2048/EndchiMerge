# Icons

工具列圖示。語意於 `design.md` §2.2 定案，共六個，其中五個成組、音符獨立。

| 檔案 | 功能 | 型態 |
| --- | --- | --- |
| `gamepad.svg` | 主頁面（遊戲本體） | 頁面切換 |
| `trophy.svg` | 排行榜 | 頁面／模態 |
| `pickaxe.svg` | 創意工坊 | 頁面（**尚未實作**，出 disabled 佔位） |
| `help.svg` | 遊戲說明 / FAQ | 模態 |
| `gear.svg` | 設定 | 頁面／模態 |
| `note.svg` | 音樂開關 | 即時切換，**不與其他五個共用選中態** |

## Notes

- 建議 **24×24 viewBox**，單色 `currentColor` 填充，方便隨選中態改色。
- 音符獨立成按鈕，不屬於左邊那組，互動上不共用選中態。
- 缺檔時退化為文字標籤，不影響功能。
