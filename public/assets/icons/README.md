# Icons

工具列圖示。實際檔案放在 `public/assets/ui/`（`ic_*.svg`），本目錄目前沒有檔案。

| 檔案（在 `../ui/`） | 功能 |
| --- | --- |
| `ic_leaderboard.svg` | 排行榜（模態） |
| `ic_creation.svg` | 創意工坊（**尚未實作**，出 disabled 佔位） |
| `ic_question.svg` | 遊戲說明 / FAQ（模態） |
| `ic_setting.svg` | 設定（模態） |
| `ic_restart.svg` | 重新開始（彈出確認對話框） |
| `ic_music.svg` | 音樂開關，獨立成鈕、**不與其他五個共用選中態** |

## Notes

- 建議 **24×24 viewBox**，單色 `currentColor` 填充，方便隨選中態改色。
- 缺檔時退化為文字標籤，不影響功能。
